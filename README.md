Необходимо создать сайт "СПЕЦАВТОСИЛА" по продажи: Отечественные и импортные комплектующие для топливозаправщиков и бензовозов.

На сайте предназначен для продажи

Предполагаемая структура БД (при необоходимости - измени)

1. Пользователь (User)
Id, Логин (UserName), Пароль (Password), Адрес электронной почты (Email), Телефон (Phone), Адрес (Address), Имя (Name), Фамилия (Surname), Отчество (Patronymic), Дата рождения (DateOfBirth), Фото (Image) ссылка на аватар, Дата рагестрация (DatOfRegistration)
2. Роль (Role)
Id, Название (Title)
3. Связь между пользователями и ролями (UserRole)
UserId, RoleId
У каждого пользователя может быть несколько ролей
3. Категории (Category)
Id, Название (Title), Описание (Description), Фото (Image) ссылка
4. Товар (Product)
Id, Название (Title), Краткое описание (ShortВescription), Подробное описание (LongDescription), Дополнительная информация (Info)
5. Связь между товарами и категориями (ProductCategoty)
CategoryId, ProductId
6. Связь между товарами и фотографиями (ProductImage)
Id,  ProductId, Название (Title), Фото (Image) ссылка,
7. Параметры сайта (Parameter)
Id, Название (Title), Значение (Value)

Главная страница сайта не требует регистрации. В верхней части расположена шапка сайта: логотип, номер телефона, адрес электронной почты и кнопка «бургер‑меню».
На мобильной версии бургер‑меню скрывает навигацию и раскрывается по нажатию.
На ПК‑версии навигация отображается сразу: Каталог, О компании, Контакты, Информация.

После шапки идёт секция с фоновой картинкой, названием сайта, кратким описанием и большой кнопкой Перейти в каталог.

Ниже располагается секция «Последние добавленные товары» — карусель из 10 последних товаров. Каждый слайд — карточка товара. Под каруселью кнопка Перейти в каталог товаров.

Следующая секция — «Самые популярные товары». Здесь также отображается до 10 товаров, определённых по количеству заказов (данные берутся из таблицы заказов). Каждый элемент — карточка товара. Под каруселью кнопка Перейти в каталог товаров.

Далее идёт секция «Преимущества заказа через наш магазин». Она делится на две части:

    выгоды для покупателя;

    перечень предоставляемых услуг.

В конце страницы расположен подвал (footer): навигация по сайту, адрес компании, контактный телефон, электронная почта и ссылки на социальные сети.

Также на главной странице под первой секцией должно быть поле поиска по сайту. Пользователь вводит название товара, нажимает «Найти» и попадает на страницу результатов поиска — список отфильтрованных товаров, соответствующих запросу.
✨ Страница каталога

Страница каталога отображает все доступные категории. Каждая категория представлена карточкой с:

    фоновой картинкой (затемнённой),

    названием,

    кратким описанием,

    кнопкой Перейти в каталог.

Карточки выводятся в виде сетки.
✨ Каталог товаров категории

После нажатия на кнопку Перейти в каталог открывается каталог товаров, отфильтрованный по выбранной категории.
Товары отображаются в виде карточек, постранично, по ~50 товаров на страницу.

Каждая карточка содержит:

    главное фото,

    название,

    кнопку Подробнее.

✨ Страница товара

Страница товара состоит из нескольких секций:

    Основной блок:

        слева — главное фото товара;

        справа — название и краткое описание.

    Кнопка «Отправить запрос»  
    По нажатию открывается всплывающее окно, где пользователь вводит:

        номер телефона (обязательно),

        адрес электронной почты (обязательно),

        пожелания (необязательно).
        После отправки создаётся запись в таблице «Заявка», и уведомление отправляется администратору на email.

    Подробное описание товара

    Дополнительная информация

    Карусель «Другие товары категории»  
    До 10 товаров из той же категории.
